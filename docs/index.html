4. Quickstart (run it yourself)

git clone https://github.com/deliciosoradha/tattvaswarm.git
cd tattvaswarm
pip install -e .                      # zero runtime dependencies
export NEBIUS_API_KEY=...              # or an NVIDIA API key + base URL override
tattva doctor
tattva route "Analyze the trade-offs of local-first AI" --tier reasoning
tattva memory add "the router prefers Nano for everyday calls"
tattva memory search Nano
