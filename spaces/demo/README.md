# TattvaSwarm — live demo

Tiered routing to NVIDIA Nemotron models on **Nebius Token Factory**
(Nano for everyday calls, Super for reasoning, Ultra for synthesis) with a
sovereign, local-first design. This Space runs one endpoint through the same
code path as the CLI (`tattva route`).

Part of the hackathon build of **TattvaSwarm** — full source, docs and evidence
live in the main repository (Apache-2.0).

Rate-limited demo: 15 calls/hour per client, prompts ≤ 1500 chars, replies
trimmed. Honest errors are shown as-is.
